## Submission Guidelines

For each laboratory exercise:

- Complete all required tasks.
- Document implementation clearly in the lab's `markdown(.md)` file.
- Include screenshots or evidence files.
- Explain the purpose of each command or configuration.
- Keep the repository organized by lab.
- Commit work regularly with meaningful commit messages.
